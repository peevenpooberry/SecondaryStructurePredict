# Retraining the Model

To run the `structure_classifier.ipynb` notebook:
1. create a new conda environment:
```
cd Model_Development
conda env create -f structure_classifier_env.yml
conda activate structure_classifier_env.yml
```
2. In the notebook choose `structure_classifier_env` as the selected kernel
3. Run the cells of the notebook with the `selected_proteins.csv` dataset or provide your own in the directory
